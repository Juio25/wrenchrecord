La aplicación de Wrench Record tiene el propósito de ser una herramienta a forma de bitácora para los usuarios apasionados de la mecánica, con esta podrán mantener un registro dinámico de los trabajos realizados a sus vehículos para poder así llevar un control de los tiempos en los que se deberán de realizar los servicios y mantenimientos de las partes de cada vehículo, ya que es fácil perderse cuando se debe de tener en cuenta a más de un vehículo.
El público objetivo para esta aplicación engloba principalmente a tres distintos tipos de usuarios con propósitos variados, los cuales son, mecánicos de fin de semana (personas que realizan sus propios trabajos de mecanica para sus propios vehículos o de conocidos), vendedores y compradores de vehículos seminuevos, y por último, coleccionistas o dueños de múltiples vehículos.
Las funcionalidades principales con las que contara la aplicación son:
Garaje Multi Vehículo: Creación de perfiles individuales con especificaciones técnicas exactas. 
Documentación de Intervenciones: Formularios dinámicos para registrar trabajos específicos. Esto abarca mantenimientos de rutina y reparaciones complejas, permitiendo detallar acciones como la purga del cilindro maestro de frenos, el diagnóstico de cableado eléctrico, el ajuste del mecanismo del ahogador del carburador o procesos estéticos como el lijado de superficies para pintura.
Alertas Preventivas: Lógica en el frontend (Angular) que calcula los intervalos de servicio basándose en el último kilometraje registrado en la API, notificando al usuario cuándo es momento de revisar componentes críticos como balatas o cambiar el tapón del radiador.
Bóveda de Evidencia Visual: Integración de cámara y subida de archivos para guardar imágenes del "antes y después". Esto es vital para que el usuario recuerde la posición exacta de mangueras o conexiones eléctricas al rearmar.
Exportación de Expediente: Generación de un reporte completo del vehículo para demostrar el cuidado que ha recibido a lo largo del tiempo.

Actualmente la aplicación cuenta con las pantallas para poder crear tu usuario, iniciar sesión, consultar la información de un usuario y el dashboard principal de la aplicación (Mi Garage) donde se podrán ver alertas de mantenimientos y los vehículos registrados.
